# NOVA FN Optimizer Free 3.0 — GitHub Pages

This is a static website package, ready to publish with GitHub Pages at no hosting cost. No Netlify credits required.

## Publish for free
1. Sign in to GitHub and create a **public** repository, e.g. `nova-fn-optimizer`.
2. Upload all files and the `icons` folder from this directory to the repository root (not the enclosing folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. Its URL will look like `https://YOUR-USERNAME.github.io/nova-fn-optimizer/`.

The site header has a **DOWNLOAD** link to `NOVA_FN_Optimizer_Free_v3.html`.

Note: this is a browser app. It does not have permission to close Windows processes or change Windows system settings. Those require a separate Windows client.
